# CampusPulse Project Overview

## Project Name

CampusPulse - Student Budget & Task Manager

## Project Purpose

CampusPulse is a web-based application designed to help students manage their personal budgets, track expenses and organise academic tasks in one place.

## Problem Statement

Students often need to manage limited money while also keeping track of assignments and academic deadlines. Managing these separately can make it difficult to understand both financial and academic responsibilities.

CampusPulse provides a single system for managing both areas.

## Main Objectives

The main objectives of CampusPulse are:

1. Allow students to create and manage an account.
2. Allow students to set a personal budget.
3. Allow students to record and track expenses.
4. Automatically calculate remaining available budget.
5. Allow students to create academic tasks.
6. Allow students to set task priorities and due dates.
7. Allow students to mark tasks as completed.
8. Provide a central dashboard showing important information.

## Technologies Used

- PHP
- MySQL
- HTML
- CSS
- XAMPP
- phpMyAdmin
- Visual Studio Code

## Main Features

### User Management

Students can register, log in and log out of the system.

### Budget Management

Students can set a budget and view how much money remains after expenses.

### Expense Tracking

Students can record expenses including descriptions, amounts and dates.

### Academic Task Management

Students can create tasks with descriptions, due dates and priority levels.

### Task Completion

Students can mark tasks as completed and view their completion status.

### Dashboard

The dashboard provides a summary of the student's budget and academic tasks.

## Security

The application uses sessions to restrict access to authenticated users.

Passwords are stored using password hashing rather than plain text.

## Conclusion

CampusPulse provides students with a simple centralised system for managing their finances and academic responsibilities.
